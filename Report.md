Использую Gunicorn вместо Flask dev-сервера: он корректно обрабатывает SIGTERM, воркеры завершают текущие запросы.На фото ниже наблюдаем: Exitcode 0 показывает, что контейнер завершился успешно, а в логах видно, что воркеры с pid 7 и 8 корректно завершили работу (Exiting)
![Pasted%20image%2020261018193435.png](Photo%20lab2/Pasted%20image%2020261018193435.png)

HEALTHCHECK проверяет `/health` через встроенный в Python `urllib` — без установки curl.

Контейнер запускается с `--read-only`. Gunicorn при старте создаёт временный файл `wgunicorn-<pid>` в `/tmp`, поэтому дополнительно монтирую `--tmpfs /tmp`, остальной контейнер остаётся `read-only`
Если этого не сделать, то контейнер не запустится с ошибкой:![Pasted%20image%2020261018185029.png](Photo%20lab2/Pasted%20image%2020261018185029.png)
